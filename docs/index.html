Features

✍️

Distraction-Free Writing

Clean, centered layout with no unnecessary UI elements. Focus on what matters: your words.

👁️

Live Markdown Preview

Side-by-side preview with synchronized scrolling. See your formatted content as you write.

🎯

Focus Modes

Sentence, paragraph, or typewriter focus modes to enhance concentration and flow.

✨

Writing Assistant

Intelligent style checking for filler words, clichés, and redundancies to improve your prose.

🌓

Light & Dark Themes

System-aware themes with manual toggle. Choose what works best for your environment.

⌨️

Keyboard-First Design

All features accessible via keyboard shortcuts. Work efficiently without touching the mouse.

Built With

Rust + Tauri

Lightweight native app (~3MB installer) with blazing fast performance

Vanilla JavaScript

No framework bloat. Just pure, efficient code

CodeMirror 6

Powerful editor with markdown support and extensibility

Installation

Prerequisites

  • Node.js (v18 or higher)
  • Rust (latest stable)
  • Platform-specific dependencies:
    • macOS: Xcode Command Line Tools
    • Linux: webkit2gtk, libssl-dev, libgtk-3-dev
    • Windows: WebView2 (usually pre-installed)

Build from Source

# Install dependencies npm install # Run in development mode npm run dev # Build for production npm run build

The built app will be in src-tauri/target/release/bundle/

For detailed documentation, see the README
